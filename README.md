# 琥珀群岛

一个基于 Three.js 和 TypeScript 的单人桌面浏览器体素岛屿沙盒。项目中的贴图、配色、音效和界面资产均为当前仓库原创生成内容，不依赖外部素材包。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm 10 或更新版本

## 常用命令

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`
- `npm run e2e:install`
- `npm run e2e`

## 操作说明

- `点击进入琥珀群岛`：进入指针锁定
- `W A S D`：移动
- `Space`：跳跃
- `鼠标移动`：视角控制
- `左键`：移除方块
- `右键`：放置当前选中方块
- `数字键 1-6`：选择对应的方块快捷栏槽位
- `快捷栏 7-9`：当前为空并预留，不能选择方块
- `滚轮`：循环切换快捷栏
- `Esc`：退出指针锁定并打开暂停菜单
- `重置世界`：清空修改并回到出生点，保留同一随机种子

## 浏览器验证

自动化浏览器测试使用 Pointer Lock 模拟器覆盖移动、跳跃、碰撞、暂停和编辑流程。发布前仍应在目标桌面浏览器中手动确认原生 Pointer Lock 的授权、鼠标捕获和 `Esc` 释放行为。

## 存档

游戏只保存版本化种子、玩家状态、当前选中槽位和方块增量，不保存完整生成世界。浏览器存档键名为 `amber-voxel-island:v1`，默认存放在当前站点的 `localStorage` 中。

## 首发排除项

以下内容明确不在首发范围内：

- 生存机制、生命、饥饿、合成、工具、敌人和战斗。
- 多人游戏或服务器端持久化。
- 无限地形流式加载。
- 移动端或手柄控制。
- 直接复用 Minecraft 的纹理、音效、品牌或名称。
- 首发版本中的动态昼夜循环。
